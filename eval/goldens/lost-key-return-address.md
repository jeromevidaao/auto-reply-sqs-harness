# Golden: Lost Key Return - Real Operational Scenario

**Scenario**: Guest finds an old key in the apartment and offers to return it.

**Real production value**: This happened multiple times. Old code had a very specific return address and polite thank-you language.

**Approved ideal behavior**:
- Thank them for being honest and considerate.
- Provide the exact return address: Richard Mondor, 53 Pine St, Apt 1F, Portland, ME, 04102

**Rubric requirements**:
- Must include the full return address
- Warm, appreciative tone for honesty
