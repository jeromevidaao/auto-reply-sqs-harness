# Golden: Sofa Bed Size & Capacity

**Scenario**: Guest asks detailed questions about the sofa bed (size, how many it sleeps, where linens are).

**Real production value**: Specific details were frequently requested and had standardized answers in production.

**Approved ideal behavior**:
- Queen size, comfortably sleeps 2, linens/pillows in the storage compartment of the sofa.

**Rubric requirements**:
- Must include queen size + sleeps 2 + storage compartment details
