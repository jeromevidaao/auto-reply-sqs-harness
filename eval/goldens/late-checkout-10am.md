# Golden: Late Checkout Request - Operational Constraint

**Scenario**: Guest requests late checkout beyond standard time.

**Real production value**: Firm 10AM checkout was consistently tied to cleaning team needs for the next guest.

**Approved ideal behavior**:
- Apologize.
- Explain 10AM + cleaning team reason.
- Do not offer flexibility unless pre-arranged.

**Rubric requirements**:
- Must reference 10AM and cleaning team
