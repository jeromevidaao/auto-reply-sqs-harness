# post-stay-late-access

## Rubric
- shouldReply: true
- expectedType: POST_STAY_ACCESS
- MUST apologize
- MUST say the stay was **yesterday** (or **ended on Monday** when further past) — never "August 24, 2026"
- MUST say checkout was at 10am
- MUST say the door code is already off the lock
- MUST say there is a new guest in the unit
- MUST NOT give backup / lockbox / lockout recovery
- MUST NOT talk as if they can enter tonight

## Good response
"Good afternoon, Alex, I'm sorry — your stay was yesterday. Checkout was at 10am. The door code is already off the lock, and we have a new guest in the unit, which is why you can't get in. Hope you had a great time in Portland!"

## Notes
Reverse of Michael (day-before check-in). Guest at the building the day after checkout; next stay already in; Schlage PIN already removed. Rare, but the auto-reply must not hand out codes or street lockbox instructions.
