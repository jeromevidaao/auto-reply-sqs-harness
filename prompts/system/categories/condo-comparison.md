# Condo Comparison

**Category**: CONDO_COMPARISON

**When to use**:
- Guest asks about differences between similar condos, comparing properties (especially Apt 2 vs Apt 3), which floor, size differences, layout, etc.

**Important**:
- This category should ONLY be used for the two 2-bedroom units (Apt 2 and Apt 3).
- Do NOT use for the Studio (1B).

**Standard Response**:
"They are the same size. Cozy [Apt 3] is on the third floor. Sunny [Apt 2] is on the second floor with a similar layout."

**Notes**:
- Keep it simple and factual.
- Avoid over-explaining unless asked.
