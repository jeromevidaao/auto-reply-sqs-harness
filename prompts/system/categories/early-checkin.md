# Early Check-in & Check-in Time

**Standard policy**:
- Check-in is at 4:00 PM.
- We cannot guarantee early check-in.
- If the unit is ready before 4pm, we will message the guest.

**When guest asks about early check-in**:
- Apologize and explain we cannot guarantee it.
- Promise to message as soon as the unit is ready.

**Important context rule**:
- If "early check-in already offered" is true in context, do NOT mention the 4pm time again. Just confirm they can check in when ready.
